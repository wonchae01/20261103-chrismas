CHRISTMAS VILLAGE 웹사이트
============================

실행 방법
1. 압축을 해제합니다.
2. index.html 파일을 Chrome 등 브라우저에서 엽니다.
3. 메인 화면의 사전등록 버튼을 누르면 register.html로 이동합니다.

폴더 구성
- index.html             메인 행사 안내 페이지
- register.html          방문 사전등록 페이지
- css/style.css          메인 페이지 스타일
- css/register.css       사전등록 페이지 스타일
- js/main.js             메뉴 및 팝업 동작
- js/register.js         신청 폼 및 완료 팝업 동작
- images/                실제 이미지 파일

수정 안내
- 행사 날짜/시간/장소: index.html의 quick-info, hero-meta, location-info 부분 수정
- 메인 사진: images/christmas-market-hero.png 교체
- 행사 소개 사진: images/market-reference.png 교체
- 색상: css/style.css 상단 :root 변수 수정
- 신청 페이지 선택 항목: register.html의 select 옵션 수정

참고
이 사이트는 웹디자인 연습용 데모입니다. 행사 날짜, 장소, 전화번호 등은 가상 정보이며,
신청 정보는 서버에 저장되거나 실제 예약/결제로 전달되지 않습니다.
Google Fonts를 불러오기 위해 인터넷 연결이 있으면 더 정확한 폰트로 표시됩니다.
